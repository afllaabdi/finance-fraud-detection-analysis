# Finance Fraud Detection ML

## Project Overview

Proyek ini bertujuan menganalisis transaksi keuangan dan mendeteksi aktivitas fraud menggunakan teknik:

- Exploratory Data Analysis (EDA)
- Feature Selection
- PCA
- t-SNE
- Machine Learning Classification

## Dataset

Dataset berisi informasi transaksi keuangan yang digunakan untuk klasifikasi fraud dan non-fraud.
